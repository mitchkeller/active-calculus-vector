Exercise 15.

Consider the iterated integral \(\displaystyle\int_{x=0}^{x=4} \int_{y=x/2}^{y=2} e^{y^2} \, dy \, dx\text{.}\)
🔗

(a)

Explain why we cannot find a simple antiderivative for \(e^{y^2}\) with respect to \(y\text{,}\) and thus are unable to evaluate \(\displaystyle\int_{x=0}^{x=4} \int_{y=x/2}^{y=2} e^{y^2} \, dy \, dx\) in the indicated order using the Fundamental Theorem of Calculus.
🔗
Solution.
No substitution will work to integrate \(e^{y^2}\) because of the square in the exponent. Using integration by parts only makes the integral more complicated, and we have no other techniques to apply to this integrand.

(c)

Rewrite the given iterated integral in the opposite order using \(dA = dx \, dy\text{.}\)
🔗
Hint.
You may need more than one integral.
🔗
🔗
Solution.
When we first integrate with respect to \(x\text{,}\) we can see that the cross sections go from \(x=0\) to \(x = 2y\text{.}\) The limits on \(y\) are then \(0\) to \(2\text{,}\) giving us
\begin{equation*} \iint_D e^{y^2} \, d = \int_0^2 \int_{0}^{2y} e^{y^2} \, dx \, dy \end{equation*}

(d)

Use the Fundamental Theorem of Calculus to evaluate the iterated integral you wrote in the previous part. Write one sentence to explain the meaning of the value you found in terms of an interpretation from Key Idea 12.1.8.
🔗
Solution.
Evaluating the iterated integral yields
\begin{align*} \int_0^4 \int_{0}^{x/2} e^{y^2} \, dy \, dx \amp = \int_0^2 \int_{0}^{2y} e^{y^2} \, dx \, dy\\ \amp = \int_0^2 xe^{y^2} \mid_{0}^{2y} \, dy\\ \amp = \int_0^2 2ye^{y^2} \, dy\\ \amp = e^{y^2} \mid_0^2\\ \amp = e^4-1\text{.} \end{align*}
Since \(e^{y^2} \gt 0\) on \(D\text{,}\) this integral tells us the volume of the solid bounded above by the surface \(z=e^{y^2}\) and below by the region \(D\text{.}\)

(e)

Write a sentence or two to describe what you have learned in this activity regarding the order in which you set up an iterated integral.
🔗
Solution.
We need to be flexible when setting up iterated integrals — sometimes one order of integration is very difficult (or impossible) while the other order is easier. So it is important to practice changing the order of integration in iterated integrals.
