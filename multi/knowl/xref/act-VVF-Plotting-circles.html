Activity 10.1.2.

The same curve can be represented with different parameterizations. Use appropriate technology to plot each of the curves generated by the following vector-valued functions for values of \(t\) from \(0\) to \(2 \pi \text{.}\) For each example, you should write a few sentences to explain how the graphs are alike and how they are different. Be sure to pay attention to how the parameter values are related to different points on the curve.
🔗

(a)

\(\vr(t) = \langle \sin(t), \cos(t) \rangle\)
🔗
Solution.
This vector-valued function is a circle traced in the clockwise direction with radius \(1\text{,}\) initial point \((0, 1)\text{,}\) and terminal point \((0, 1)\text{.}\)
🔗
🔗
🔗

(b)

\(\vr(t) = \langle \sin(2t), \cos(2t) \rangle\)
🔗
Solution.
This vector-valued function is a circle traced in the clockwise direction with radius \(1\text{,}\) initial point \((0, 1)\text{,}\) and terminal point \((0, 1)\text{,}\) but the circle is traced twice since the period of the parametric trigonometric functions are \(\pi\text{.}\)
🔗
🔗
🔗

(c)

\(\vr(t) = \langle \cos(t+\pi), \sin(t+\pi) \rangle\)
🔗
Solution.
This vector-valued function is a circle traced in the clockwise direction with radius \(1\text{,}\) initial point \((0, -1)\text{,}\) and terminal point \((0, -1)\text{.}\)
🔗
🔗
🔗

(d)

\(\vr(t) = \langle \cos(t^2), \sin(t^2) \rangle\)
🔗
Solution.
This vector-valued function is a circle traced in the clockwise direction with radius \(1\text{,}\) initial point \((0, 1)\text{,}\) and terminal point \((sin(4(\pi)^2), cos(4(\pi)^2))\text{.}\) The circle is traced multiple times.
