part 9.4.2.d.

Recall that multiplication of real numbers is associative. For example, \((2\cdot 5)\cdot 3 = 2\cdot(5\cdot 3)\text{.}\) Is it true that the cross product of vectors is associative? For instance, is it true that \((\vu\times\vv)\times\vi = \vu\times(\vv\times\vi)\text{?}\)
🔗
Solution.
\((\vu \times \vv) \times \vi = \langle 3, 6, -2\rangle \times \langle 1, 0, 0\rangle\text{.}\)
🔗
\(= ((6)(0) - (0)(-2))\vi - ((3)(0) - (1)(-2))\vj + ((3)(0) - (6)(1))\vk = 0\vi + -2\vj + -6\vk = -2\vj - 6\vk\text{.}\)
🔗
\(\vu \times (\vv \times \vi) = \langle 0, 1, 3\rangle \times \langle 0, 0, 1\rangle\text{.}\)
🔗
\(= ((1)(1) - (3)(0))\vi - ((0)(1) - (0)(3))\vj + ((0)(0) - (1)(0))\vk = 1\vi + 0\vj + 0\vk = \vi\text{.}\)
🔗
The associative property does not hold for the cross product.
