(f)

To find the volume of the rectangular prisms over each \(R_{i j}\text{,}\) we must pick a point in each subrectangle at which to evaluate \(f\text{,}\) which will be the height of the rectangular prism. For this activity, we will use the upper-right corner of each subrectangle as the designated point.
🔗
State the point at the upper right of each smaller rectangle and evaluate \(f\) at each of these points.
🔗
Solution.
With \([a,b] = [0,8]\) and \([c,d] = [2,6]\text{,}\) we have \(\Delta x = 2\) and \(\Delta y = \frac{4}{3}\text{.}\) So \((x_{11}^*,y_{11}^*) = \left(2, \frac{10}{3}\right)\) as shown in the figure below. Then
\begin{equation*} f(x_{11}^*,y_{11}^*) \Delta A = f\left(2, \frac{10}{3}\right) (2)\left(\frac{4}{3}\right) = \left(\frac{764}{9}\right)\frac{8}{3} = \frac{6112}{27} \approx 226.37 \end{equation*}
This result represents the volume of a box with height \(f(x_{11}^*,y_{11}^*)\) and base given by the rectangle \([x_0, x_1] \times [y_0, y_1]\text{.}\)

If we add all the values \(f(x_{ij}^*,y_{ij}^*) \Delta A\) for each \(i\) and \(j\text{,}\) the resulting number approximates the volume of the solid bounded above by the surface defined by \(f\) and below by the rectangle \(R\text{.}\)
\begin{equation*} \sum_{j=1}^3 \sum_{i=1}^4 f(x_{ij}^*,y_{ij}^*) \Delta A \end{equation*}

(h)

We chose the upper-right point of each subrectangle \(R_{i j}\) to find the height of each rectangular prism used in the approximation. Write a sentence or two about whether you think the upper right point provides an overestimate, an underestimate, or approximately the average value for \(f\) on each \(R_{i j}\text{.}\) Explain how this suggests that your estimate for the volume under the surface \(z=f(x,y)\) over the region \(R\) is either an overestimate, an underestimate, or approximately the correct value.
🔗
Solution.
The upper right point in each subrectangle will give the largest x and y coordinates for the region and larger x and y will correspond to smaller \(f(x,y)\text{,}\) so the upper right point will underestimate the heights for each sub region. Thus the sum of these estimates will underestimate the total volume under our surface.
