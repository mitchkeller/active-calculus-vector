Activity 11.4.2.

(a)

Find all second-order partial derivatives of the following functions. For each partial derivative you calculate, state explicitly which variable is being held constant.
🔗

(i)

\(f(x,y) = x^2y^3\)
🔗
Solution.
To begin, we calculate the first-order partials, holding \(y\) constant to calculate \(f_x\) and \(x\) constant to calculate \(f_y\text{:}\)
\begin{align*} f_x(x,y) \amp = 2xy^3\\ f_y(x,y) \amp = 3x^2y^2 \end{align*}
The second-order partial derivatives are partial derivatives of the first-order partial derivatives:
\begin{align*} f_{xx}(x,y) \amp = (f_x)_x(x,y) = 2y^3\\ f_{xy}(x,y) \amp = (f_x)_y(x,y) = 6xy^2\\ f_{yx}(x,y) \amp = (f_y)_x(x,y) = 6xy^2\\ f_{yy}(x,y) \amp = (f_y)_y(x,y) = 6x^2y \end{align*}
🔗
🔗
🔗

(ii)

\(y(q,p) = p\cos(q)\)
🔗
Solution.
To begin, we calculate the first-order partials:
\begin{align*} y_q(x,y) \amp = -p\sin(q)\\ y_p(x,y) \amp = \cos(q)\text{.} \end{align*}
The second-order partial derivatives are partial derivatives of the first-order partial derivatives:
\begin{align*} y_{qq}(x,y) \amp = (y_q)_q(q,p) = -p\cos(q)\\ y_{qp}(x,y) \amp = (y_q)_p(q,p) = -\sin(q)\\ y_{pq}(x,y) \amp = (y_p)_q(q,p) = -\sin(q)\\ y_{pp}(x,y) \amp = (y_p)_p(q,p) = 0 \end{align*}
🔗
🔗
🔗

(iii)

\(g(s,t) = st^3 + s^4\)
🔗
Solution.
To begin, we calculate the first-order partials, holding \(t\) constant to calculate \(g_s\) and \(s\) constant to calculate \(g_t\text{:}\)
\begin{align*} g_s(s,t) \amp = t^3+4s^3\\ g_t(s,t) \amp = 3st^2\text{.} \end{align*}
The second-order partial derivatives are partial derivatives of the first-order partial derivatives:
\begin{align*} g_{ss}(s,t) \amp = (g_s)_s(s,t) = 12s^2\\ g_{st}(s,t) \amp = (g_s)_t(s,t) = 3t^2\\ g_{ts}(s,t) \amp = (g_t)_s(s,t) = 3t^2\\ g_{tt}(s,t) \amp = (g_t)_t(s,t) = 6st \end{align*}

(b)

If \(h(x,y,z,t) = 9x^9z-xyz^9 + 9t\text{,}\) how many second-order partial derivatives does the function \(h\) have? Write a sentence to justify your reasoning on the number of second-order partial derivatives of \(h\text{.}\) Finally, find \(h_{xz}\) and \(h_{zx}\) (you do not need to find the other second-order partial derivatives).
🔗
Solution.
Since \(h\) is a function of four independent variables, \(h\) has four first-order partial derivatives: \(h_x, h_y\text{,}\) \(h_z\text{,}\) and \(h_t\text{.}\) Each of those has four partial derivatives, so \(h\) has sixteen second-order partial derivatives.
🔗
To find \(h_{xz}\text{,}\) we start by calculating \(h_x\text{,}\) holding \(y, z, t\) constant and differentiating with respect to \(x\text{:}\)
\begin{equation*} h_x (x, y, z) = 81x^8z - yz^9 \end{equation*}
We then take the partial derivative of \(h_x\) with respect to \(z\text{,}\) holding \(x\) and \(y\) constant:
\begin{equation*} h_{xz} (x, y, z) = 81x^8 - 9yz^8 \end{equation*}
Similarly, to find \(h_{zx}\text{,}\) we start by calculating \(h_z\text{,}\) holding \(x, y, t\) constant and differentiating with respect to \(z\text{:}\)
\begin{equation*} h_z (x, y, z) = 9x^9 - 9xyz^8 \end{equation*}
We then take the partial derivative of \(h_z\) with respect to \(x\text{,}\) holding \(y\) and \(z\) constant:
\begin{equation*} h_{zx} (x, y, z) = 81x^8 - 9yz^8 \end{equation*}
