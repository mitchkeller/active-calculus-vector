part 9.2.3.e.

So we need to get from point \(S\) to point \(D\text{.}\) Explain how to use the components of \(\overrightarrow{CS}\) and \(\overrightarrow{CD}\) to find the components of \(\overrightarrow{SD}\text{.}\)
🔗
Solution.
Because \(\overrightarrow{CS}\) and \(\overrightarrow{CD}\) describe the displacement from the same location to \(S\) and \(D\text{,}\) we can look at the componentwise difference between these vectors to get the displacement from \(S\) to \(D\text{.}\) The displacement in the East/West direction from \(S\) to \(D\) will be the difference in the first components of the vectors \(\overrightarrow{CS}\) and \(\overrightarrow{CD}\) and similarly for the second components to be used to find the North/South displacement. So, to find the components of
\begin{equation*} \overrightarrow{SD}= \overrightarrow{CD}-\overrightarrow{CS}=\langle 9,12 \rangle -\langle 1,5 \rangle = \langle 8,7 \rangle \end{equation*}
