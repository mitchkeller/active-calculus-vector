Activity 10.2.2.

For each of the following vector-valued functions, state any values of \(a\) for which \(\displaystyle\lim_{t\to a}\vr(t)\) will not exist and find \(\vr\, '(t)\text{.}\)
🔗

(a)

\(\vr(t) = \langle \cos(t), t\sin(t), \ln(t) \rangle\text{.}\)
🔗
Solution.
The third component of this function will is only defined when \(t\geq 0\text{.}\) The limit as \(t\to a\) of this function will exist if \(a\geq 0\text{.}\) Differentiating componentwise gives
\begin{equation*} \vr\, '(t) = \left\langle -\sin(t), t\cos(t)+\sin(t), \frac{1}{t} \right\rangle\text{.} \end{equation*}
🔗
🔗
🔗

(b)

\(\vr(t) = \langle t^2 + 3t, e^{-2t}, \displaystyle\frac{t}{t^2 + 1} \rangle\text{.}\)
🔗
Solution.
Each component of this function will have limits that exist for every input. Differentiating componentwise gives
\begin{equation*} \vr\, '(t) = \left\langle 2t+3, -2e^{-2t}, \displaystyle\frac{1-t^2}{1+t^2} \right\rangle\text{.} \end{equation*}
🔗
🔗
🔗

(c)

\(\vr(t) = \langle \tan(t), \cos(t^2), te^{-t} \rangle\text{.}\)
🔗
Solution.
The limit as \(t\to a\) of the first component of this function does not exist for values of \(a\) of the form \(\frac{(2k+1)\pi}{2}\) with \(k\in\mathbb{Z}\text{.}\) Differentiating componentwise gives
\begin{equation*} \vr\, '(t) = \left\langle \sec^2(t), -2t\sin(t^2), -te^{-t}+e^{-t} \right\rangle\text{.} \end{equation*}
🔗
🔗
🔗

(d)

\(\vr(t) = \left\langle \sqrt{t^4 + 4}, \frac{2}{t^2+t} , e^{2t} \sin(-2t) \right\rangle\text{.}\)
🔗
Solution.
Each component of this function will have limits that exist for every input. Differentiating componentwise gives
\begin{equation*} \vr\, '(t) = \left\langle \frac{2t^3}{\sqrt{t^4 + 4}}, 3\cos(3t), -4\sin(4t) \right\rangle\text{.} \end{equation*}
