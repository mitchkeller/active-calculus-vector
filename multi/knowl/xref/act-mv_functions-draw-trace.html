Activity 11.1.4.

In this activity, we investigate the use of traces to better understand a function through both tables and graphs.
🔗

(a)

Identify the \(y = 0.6\) trace for the distance function \(f\) defined by \(f(x,y) = \frac{x^2 \sin(2y)}{g}\) by highlighting or circling the appropriate cells in Table 11.1.6. Write a sentence to describe the behavior of the function along this trace.
🔗
Solution.
The \(y = 0.6\) trace is the vertical column in Table 11.1.6 where \(y = 0.6\text{.}\) If the launch angle is \(0.6\) radians, as the initial velocity increases, the range of the object increases at an increasing rate.
🔗
🔗
🔗

(b)

Identify the \(x = 150\) trace for the distance function by highlighting or circling the appropriate cells in Table 11.1.6. Write a sentence to describe the behavior of the function along this trace.
🔗
Solution.
The \(x = 150\) trace is the horizontal row in Table 11.1.6 where \(x = 150\text{.}\) If the initial velocity is \(150 \frac{feet}{sec}\text{,}\) as the launch angle increases from \(0.2\) radians to \(0.8\) radians, the range of the object increases. When the launch angle increases from \(0.8\) radians to \(1.4\text{,}\) the range of the object decreases.
🔗

(c)

In the next several parts, we will be looking at using traces to help us draw an accurate plot of the surface given by \(z=g(x,y)=yx^2\text{.}\) As a first step, find the equation for the \(y=1\) trace of \(z=g(x,y)=yx^2\) and draw a graph of the \(y=1\) trace on the corresponding face in Figure 11.1.13.
🔗
Solution.
The trace with \(y=1\) will correspond to the graph of \(z=x^2\text{,}\) which will be drawn on the right wall of the default viewpoint on our figure.

(e)

Draw a few traces (at least three more) that correspond to values in the middle of the plot to fill in a plot of the surface given by \(z=x^2y\text{.}\)
🔗
Solution.
A three dimensional plot of sides of a box shown in gray. The sides of this box are shown with a grid from negative one to one in both the horizontal and vertical coordinates. A plot of the traces for z=yx^2 is shown with the constant values of x shown in blue and constant values of y shown in red. var('t,s,x,y') vs=[-1,-0.5,0,0.5,1] f(x,y)=y*x^2 plot15=parametric_plot3d((1,s,t),(s,-1,1),(t,-1,1),color="gray",opacity=0.1,plot_points=5,aspect_ratio=[1,1,0.5]) plot15+=parametric_plot3d((-1,s,t),(s,-1,1),(t,-1,1),color="gray",opacity=0.1,plot_points=5) plot15+=parametric_plot3d((s,1,t),(s,-1,1),(t,-1,1),color="gray",opacity=0.1,plot_points=5) plot15+=parametric_plot3d((s,-1,t),(s,-1,1),(t,-1,1),color="gray",opacity=0.1,plot_points=5) for v in vs: plot15+=parametric_plot3d((s,v,f(s,v)),(s,-1,1),color="red",thickness=2) plot15+=parametric_plot3d((v,s,f(v,s)),(s,-1,1),color="blue",thickness=2) show(plot15)
