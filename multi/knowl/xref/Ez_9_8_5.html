Exercise 6.

In this exercise we verify the curvature formula
\begin{equation*} \kappa = \frac{\lvert \vr'(t) \times \vr''(t) \rvert}{\lvert \vr'(t) \rvert^3}. \end{equation*}
🔗

(a)

Explain why
\begin{equation*} \lvert \vr'(t) \rvert = \frac{ds}{dt}. \end{equation*}
🔗
Solution.
We showed that \(\frac{d \vr}{ds} = 1\text{,}\) so the Chain Rule shows that
\begin{equation*} \lvert \frac{d \vr}{dt} \rvert = \lvert \frac{d \vr}{ds} \frac{ds}{dt} \rvert = \lvert \frac{d \vr}{ds} \rvert \lvert \frac{ds}{dt} \rvert = \lvert \frac{ds}{dt} \rvert = \frac{ds}{dt}\text{,} \end{equation*}
since \(s\) is an increasing function.
🔗
🔗
🔗

(b)

Use the fact that \(\vT(t) = \frac{\vr'(t)}{\lvert \vr'(t) \rvert}\) and \(\lvert \vr'(t) \rvert = \frac{ds}{dt}\) to explain why
\begin{equation*} \vr'(t) = \frac{ds}{dt} \vT(t). \end{equation*}
🔗
Solution.
Note that
\begin{equation*} \vr'(t) = \lvert \vr'(t) \rvert \vT(t) = \frac{ds}{dt} \vT(t)\text{.} \end{equation*}
🔗
🔗
🔗

(c)

The Product Rule shows that
\begin{equation*} \vr''(t) = \frac{d^2s}{dt^2} \vT(t) + \frac{ds}{dt} \vT'(t). \end{equation*}
Explain why
\begin{equation*} \vr'(t) \times \vr''(t) = \left(\frac{ds}{dt}\right)^2 (\vT(t) \times \vT'(t)). \end{equation*}
🔗
Solution.
Using the previous results we see that
\begin{align*} \vr'(t) \times \vr''(t) \amp = \left( \frac{ds}{dt} \vT(t) \right) \times \left( \frac{d^2s}{dt^2} \vT(t) + \frac{ds}{dt} \vT'(t) \right)\\ \amp = \left( \frac{ds}{dt} \vT(t) \times \frac{d^2s}{dt^2} \vT(t) \right) + \left( \frac{ds}{dt} \vT(t) \times \frac{ds}{dt} \vT'(t) \right)\\ \amp = \left( \frac{ds}{dt} \right) \left( \frac{d^2s}{dt^2} \right) \left( \vT(t) \times \vT(t) \right) + \left( \frac{ds}{dt} \right) \left( \frac{ds}{dt} \right) \left( \vT(t) \times \vT'(t) \right)\\ \amp = \left(\frac{ds}{dt}\right)^2 (\vT(t) \times \vT'(t))\text{.} \end{align*}
🔗
🔗
🔗

(d)

In Key Idea on \(\vT\) and \(\vN\) we showed that \(\lvert \vT(t) \rvert = 1\) implies that \(\vT(t)\) is orthogonal to \(\vT'(t)\) for every value of \(t\text{.}\) Explain what this tells us about \(\lvert \vT(t) \times \vT'(t) \rvert\) and conclude that
\begin{equation*} \lvert \vr'(t) \times \vr''(t) \rvert = \left(\frac{ds}{dt}\right)^2 \lvert \vT'(t) \rvert. \end{equation*}
🔗
Solution.
We know that
\begin{equation*} \vT(t) \times \vT'(t) = \lvert \vT(t) \rvert \lvert \vT'(t) \rvert \sin\left(\frac{\pi}{2}\right) \vn \end{equation*}
for some unit vector \(\vn\) orthogonal to both \(\vT(t)\) and \(\vT'(t)\text{.}\) So
\begin{equation*} \lvert \vT(t) \times \vT'(t) \rvert = \lvert \vT(t) \rvert \lvert \vT'(t) \rvert \sin\left(\frac{\pi}{2}\right) \lvert \vn \rvert = \lvert \vT'(t) \rvert\text{.} \end{equation*}
It follows that
\begin{equation*} \lvert \vr'(t) \times \vr''(t) \rvert = \left(\frac{ds}{dt}\right)^2 \lvert \vT(t) \times \vT'(t) \rvert = \left(\frac{ds}{dt}\right)^2 \lvert \vT'(t) \rvert\text{.} \end{equation*}
🔗
🔗
🔗

(e)

Finally, use the fact that \(\kappa = \frac{\lvert \vT'(t) \rvert }{\lvert \vr'(t) \rvert}\) to verify that
\begin{equation*} \kappa = \frac{\lvert \vr'(t) \times \vr''(t) \rvert}{\lvert \vr'(t) \rvert^3}. \end{equation*}
🔗
Solution.
We have
\begin{equation*} \lvert \vT'(t) \rvert = \frac{\lvert \vr'(t) \times \vr''(t) \rvert}{\left(\frac{ds}{dt}\right)^2} \end{equation*}
and so
\begin{align*} \kappa \amp = \frac{\lvert \vT'(t) \rvert }{\lvert \vr'(t) \rvert}\\ \amp = \frac{\lvert \vr'(t) \times \vr''(t) \rvert }{\left(\frac{ds}{dt}\right)^2 \lvert \vr'(t) \rvert}\\ \amp = \frac{\lvert \vr'(t) \times \vr''(t) \rvert }{\left( \lvert \vr'(t) \rvert \right)^2 \lvert \vr'(t) \rvert}\\ \amp = \frac{\lvert \vr'(t) \times \vr''(t) \rvert}{\lvert \vr'(t) \rvert^3}\text{.} \end{align*}
